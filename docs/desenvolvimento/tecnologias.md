# Tecnologias Utilizadas

As tecnologias do projeto foram organizadas conforme sua função na arquitetura da plataforma.

## Frontend

| Tecnologia | Finalidade |
|---|---|
| React | Construção da interface baseada em componentes |
| TypeScript | Tipagem estática e maior segurança no código |
| Vite | Ambiente de desenvolvimento e processo de build |
| Tailwind CSS | Estilização responsiva da interface |
| Axios | Comunicação HTTP entre frontend e backend |
| React Router | Gerenciamento de rotas e navegação |

## Backend

| Tecnologia | Finalidade |
|---|---|
| Python | Linguagem principal do backend |
| FastAPI | Desenvolvimento da API REST |
| Pydantic | Validação e serialização dos dados |
| JWT | Autenticação baseada em tokens |
| Bcrypt | Proteção das senhas |
| SQLAlchemy | Mapeamento objeto-relacional |
| SQLModel | Organização de modelos e persistência |

## Banco de dados

| Tecnologia | Finalidade |
|---|---|
| PostgreSQL | Persistência dos dados relacionais |
| Alembic | Controle de migrações do banco de dados |

## Integrações externas

| Tecnologia ou serviço | Finalidade |
|---|---|
| Mercado Pago | Processamento de pagamentos |
| SMTP | Envio de e-mails automáticos |

## Desenvolvimento e colaboração

| Ferramenta | Finalidade |
|---|---|
| Git | Controle de versão |
| GitHub | Repositórios, colaboração e revisão |
| GitHub Projects | Organização das atividades |
| Figma | Prototipação visual |
| VS Code | Ambiente de desenvolvimento |
| GitHub Pages | Publicação da documentação |

## Observações

A presença de uma tecnologia no planejamento não garante que ela esteja completamente configurada ou em produção.

O estado efetivo deve ser comparado com os repositórios de frontend e backend e registrado em [Status Atual da Implementação](../introducao/status_atual.md).
